# Identifiability in Heterogeneous Agent-Based Models

Matlab code to produce figures for upcoming paper on identifiability in heterogeneous agent-based models.

To reproduce the figures, run startup.m then go into the figures directory and run the corresponding figure script, e.g. fig1_theta2type.m will produce figure 1 in the paper. Figures 3 onwards use pre-produced data. The data can be reproduced by going into the data directory and running the corresponding data script, e.g. data3_2typeerror.m will produce the data used by fig3_2typeerror.m
